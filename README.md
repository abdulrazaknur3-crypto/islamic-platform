# Injazak — إنجازك

موقع One-Page احترافي لمكتب إنجازك لخدمات ومتابعة وتعقيب المعاملات، مع لوحة داخلية لإدارة الطلبات والأخبار.

## التقنية
- Next.js 16.3.4
- React 19.2
- Tailwind CSS 4.3
- Supabase
- Vercel

## المسارات
- `/` الصفحة العامة الوحيدة.
- `/admin/login` دخول الفريق.
- `/admin` لوحة الإدارة الداخلية.
